## 本版更新

### 实时修改（Trainer）

- **默认预设不再在启动修改时自动写入**；附加后仅读取游戏当前数值，需手动点预设 **「应用」** 才会写入
- 「设为默认」/「取消默认」拆为两个独立按钮
- GameAssembly 热更新后自动重定位 typeinfo / manager 偏移
- 移动速度、暴击伤害等面板读数与游戏 UI 对齐；排除战斗中动态叠层修饰符对面板显示的干扰
- 角色/咒语伤害读数纳入 `HiddenStatModifier`；咒语 Tab 伤害合并角色加成时与游戏面板一致
- 暴击伤害（FLAT 计算）读取时排除攻击叠层等动态修饰符，面板值不再跳动
- 基础 Tab「咒语伤害 %」按游戏规则只累计正向修饰符（含护甲增伤 artifact，不含负向置换 debuff）

## 快速上手

1. **改存档**：关闭游戏 → 编辑 → 顶栏「应用修改」
2. **局内改属性**：启动游戏并进对局 → 「启动修改」→ 改数值后 **Enter** 生效
3. **预设**：选中预设 → **预览** 查看 → **应用** 写入游戏（需已附加）；**设为默认** 仅作标记，不会自动覆盖
4. **断开附加**：点击 **「断开附加重置数据」** 停止实时修改

---

## 从旧版升级

- 覆盖 exe 即可；`config/`（主题、存档路径、预设）会保留
- 若曾依赖「启动即套默认预设」，请改用手动 **应用** 预设
