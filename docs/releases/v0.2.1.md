## 快速上手

1. **改存档**：关闭游戏 → 编辑 → 顶栏「应用修改」
2. **局内改属性**：启动游戏并进对局 → 「启动修改」→ 改数值后 **Enter** 生效
3. **断开附加**：对局内点击 **「断开附加重置数据」** 停止实时修改并清空面板
4. **预设**：选中预设 → **预览** 查看数值 → **应用** 写入游戏（需已附加）

---

## 从旧版升级

- 覆盖 exe 即可；`config/`（主题、存档路径、预设）会保留
- 自 v0.2.0 升级无需额外操作
