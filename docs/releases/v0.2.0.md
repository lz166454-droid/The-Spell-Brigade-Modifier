## 本版更新

### 实时修改（Trainer）

- 按咒语动态显示可改属性（不再写死 3 项）
- 修正咒语名称映射（如太阳脉冲）
- 修正咒语面板数值与游戏不一致（咒语范围等与角色加成合并计算）
- **属性预设**：保存 / 应用 / 设为默认；**预览**仅更新界面、不写游戏
- 预设覆盖「基础 + 隐藏」共 20 项属性

### 界面

- 中 / 英切换、浅 / 深色主题
- 存档编辑与实时修改分 Tab 导航

### 存档编辑

- 概览 / 角色 / 成就编辑，应用前自动备份

---

## 快速上手

1. **改存档**：关闭游戏 → 编辑 → 顶栏「应用修改」
2. **局内改属性**：启动游戏并进对局 → 「启动修改」→ 改数值后 **Enter** 生效
3. **预设**：选中预设 → **预览** 查看数值 → **应用** 写入游戏（需已附加）

---

## 从旧版升级

- 覆盖 exe 即可；`config/`（主题、存档路径、预设）会保留
- v0.1.0 及更早保存的预设不含隐藏属性，请重新「保存为…」一次
